## DS-Explorer: nur gepruefte fertige Programme

Der DS-Explorer wird **privat entwickelt und lokal kompiliert**. Dieses oeffentliche Repository ist nur ein Download-/Updatekanal fuer explizit freigegebene binaere Releases samt Version und Pruefsummen. Der DS-Explorer-Quellcode, interne Sicherheitslogik, Lizenz- und Signierschluessel sowie NAS-/VPN-Zugangsdaten werden hier nicht hinterlegt.

**Keine automatische Veroeffentlichung ungepruefter Builds.** Neue Pakete werden erst nach Sicherheitskontrolle, gueltigen Signaturen und erfolgreichen Installationstests freigegeben. Ein oeffentlicher Download ist keine Freigabe zum Ueberschreiben bestehender Installationen.
